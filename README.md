# 月下審判：魔法少女倖存者

暗黑又帶點可愛的哥德風「倖存者」類網頁遊戲，以手機橫向操作為主。
玩法沿用 [葉語冒險：倖存者](https://github.com/kongwang1028a-sketch/leaf-survivors)，角色、魔物、場景與美術全部原創，以 Canvas 程式繪製。

## 怎麼玩
直接用瀏覽器開啟 `index.html`，不需要安裝或建置。

- 手機：左半邊螢幕是滑動搖桿，可以往八個方向移動；右半邊點一下衝刺，衝刺的瞬間無敵
- 電腦：WASD／方向鍵移動，空白鍵衝刺，P 暫停

## 內容
- 場景：夜晚的審判庭中庭，石磚地、十字紅毯、中央魔法陣、哥德路燈、紫葉枯樹、斷柱、燭台、玫瑰花瓣與螢火
- 4 位魔法少女，Lv.10 覺醒二選一：

  | 魔法少女 | 起始魔法 | 覺醒 A | 覺醒 B |
  |---|---|---|---|
  | 🌘 月蝕 | 月鐮斬 | 紅月收割者（血月斬） | 銀十字修女（聖十字） |
  | 🎶 緋紅聖歌 | 聖歌音符 | 業火詠唱（業火流星） | 星夜詠唱（星夜結界） |
  | 🎭 人偶師 | 銀針 | 絲雨織者（銀針雨） | 玩偶之友（熊熊玩偶） |
  | ⏱️ 時之證人 | 時針飛刃 | 鏡像證人（鏡中倒影） | 發條陷阱師（發條炸彈） |

- 共用魔法 9 種，滿級後可昇華成 13 種禁忌魔法
- 魔物：小怨靈、蝙蝠使魔、詛咒人偶；3:00 石像審判長、6:00 最終審判長
- 沉睡的魔物：荊棘魔女、鐵棺騎士、夜鴉伯爵，打倒後可契約使魔
