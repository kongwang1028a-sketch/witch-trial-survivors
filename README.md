# 月下審判：魔法少女倖存者

暗黑又帶點可愛的哥德風「倖存者」類網頁遊戲，以手機橫向操作為主。
玩法沿用 [葉語冒險：倖存者](https://github.com/kongwang1028a-sketch/leaf-survivors)，角色、魔物與美術全部原創：角色與魔物為 Canvas 程式繪製的點陣圖，地板、紅毯、魔法陣、路燈、斷柱、碎石、水窪與燭台使用 AI 產生的圖片（WebP／PNG 內嵌於 HTML）。

## 怎麼玩
直接用瀏覽器開啟 `index.html`，不需要安裝或建置。

- 手機：左半邊螢幕是滑動搖桿，可以往八個方向移動；右半邊點一下衝刺，衝刺的瞬間無敵
- 電腦：WASD／方向鍵移動，空白鍵衝刺，P 暫停

- 4 位魔法少女，全部是 2.5D 點陣角色（有正面、背面、走路與攻擊動作），Lv.10 覺醒二選一並換裝：

## 魔女商店

每局撿到的金幣、存活獎勵（每 3 秒 1 枚）與通關獎勵會存進金庫，跨局保留（存在瀏覽器）。

- **永久強化**：生命、魔法傷害、移動速度、減傷、撿取範圍、經驗值、金幣加成、開局升級、每局一次復活
- **扭蛋**：單抽 120／十連 1080（十連必有稀有以上），機率普通 62%・稀有 30%・傳說 8%，30 抽內必得傳說
- **衣櫥**：頭飾、足跡、光環共 19 種外觀，只改變樣子不影響強度；重複的轉成碎片，可兌換指定外觀

第 2 關需要先通關第 1 關才會解鎖。
